## Описание

Веб-приложение на Laravel для учебной организации. Система централизует учет пропусков занятий, управление
пользователями и ролями, работу с группами/предметами/кураторами, переводы (transfer), заявки преподавателей и
формирование отчетов (PDF/архивы).

Ключевая проблема, которую решает проект: разрозненное и ручное ведение учета посещаемости и кадрово-учебных операций.

## Цели и задачи

- Обеспечить единый контур учета пропусков и связанных учебных сущностей.
- Автоматизировать регулярные процессы (ежедневные/недельные/месячные/интервальные задачи, закрытие сессий входа).
- Дать управленческие инструменты: администрирование пользователей, ролей, прав, переводов и заявок.
- Снизить ручной труд через импорт, экспорт и фоновые задачи.

Ключевые задачи:

- Учет пропусков по группе/дате/паре/предмету/преподавателю.
- Назначение совместителя по пропуску и контроль прав доступа.
- Управление составом групп (студенты, кураторы, старосты, преподаватели).
- Выполнение и откат переводов с логированием.
- Обработка заявок преподавателей на добавление/удаление групп и предметов.
- Формирование PDF-отчетов и пакетный экспорт в ZIP.

## Функциональность

- Основные возможности:
  - Авторизация, выход, сброс пароля через email.
  - Управление пользователями, ролями и permissions.
  - Управление группами, специализациями, предметами, назначениями преподавателей.
  - Учет пропусков: создание, просмотр, фильтрация, корректировки (в т.ч. робот-режим).
  - Переводы (global/local, initialize, rollback) с журналированием.
  - Заявки преподавателей (item/group, добавление/удаление, статусы).
  - Просмотр статистики и рейтинговых срезов.

- Дополнительные функции:
  - Импорт пользователей и предметов из файлов (Laravel Excel).
  - Экспорт отчетов по пропускам в PDF и пакетный экспорт в ZIP через очередь.
  - Real-time уведомления о статусе экспорта через broadcasting/private channels.
  - Логирование действий в БД через Monolog handler.
  - Трекинг истории посещённых URL (асинхронная запись job).
  - Планировщик cron-команд для регулярных операций.

## Архитектура

- Общая структура системы:
  - `Http` слой: Controllers + Form Requests + Middleware.
  - `DI` слой: сервисы и репозитории (интерфейсы + реализации).
  - `Models` (Eloquent): доменные сущности и связи.
  - `Common` модули: transfer, truancy, import/pdf, file storage, lock, filter, paginator и др.
  - `CQRS` модуль: отдельный контур команд/запросов (на текущий момент активно для модуля Student).
  - Асинхронный слой: `Jobs`, `Events`, `Listeners`, `Mail`, `Console` commands.

- Используемые технологии в архитектуре:
  - Сервис-ориентированная организация с DI-контейнером (`AppServiceProvider`, отдельные module providers).
  - Паттерны: Repository, Service Layer, Command Handler (в transfer), CQRS (CommandBus/QueryBus), Pipeline
    middleware.
  - Транзакционность и `afterCommit` для критичных операций.
  - Queue + Broadcasting для долгих процессов и прогресса экспорта.

- Взаимодействие компонентов:
  - Пользовательский запрос → Controller → Service (`DI\Service\...`) → Repository/Model.
  - Для сложных кейсов: Service инициирует доменные команды (`Common\...\Command`) в транзакции.
  - Долгие операции (экспорт, URL-лог) уходят в Jobs.
  - Jobs публикуют Events; UI получает статусы через private broadcast channel.
  - Планировщик запускает консольные команды для периодических отчетов и регламентных действий.

## Технологии

| Backend              | PHP 8.2, Laravel 10, Eloquent ORM, Laravel Sanctum                              |

| Очереди и события    | Laravel Queue, Events/Listeners, Broadcasting, Pusher                           |
| Интеграции           | GuzzleHTTP (внешнее расписание), AWS S3 (Flysystem), Email (Mailable/Queue)     |
| Документы и импорт   | `barryvdh/laravel-dompdf`, `maatwebsite/excel`, ZIP-архивирование               |
| Логирование          | Monolog + кастомный DB handler                                                  |
| Frontend             | Vite, Tailwind CSS, Flowbite, Axios, Laravel Echo, Pusher JS, Chart.js, Sass    |
